# Low Level Design (LLD)

This repository contains my implementations and notes on various **Low Level Design (LLD)** concepts, **SOLID Principles**, and **Design Patterns** using Java.

The purpose of this repository is to strengthen object-oriented design skills, understand software design principles, and build a solid foundation in designing maintainable and scalable software systems.

---

## Topics Covered

### Object-Oriented Programming (OOP)

* Classes & Objects
* Encapsulation
* Abstraction
* Inheritance
* Polymorphism

### SOLID Principles

* Single Responsibility Principle (SRP)
* Open/Closed Principle (OCP)
* Liskov Substitution Principle (LSP)
* Interface Segregation Principle (ISP)
* Dependency Inversion Principle (DIP)

### Creational Design Patterns

* Singleton Pattern
* Factory Method Pattern
* Abstract Factory Pattern

### Structural Design Patterns

* Adapter Pattern
* Decorator Pattern

### Behavioral Design Patterns

* Observer Pattern
